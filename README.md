# 駐車券どこ行った？トラブル回避スマート保管場所カメラ

駐車場の入口で受け取った駐車券の車内での紛失を防ぐため、写真と座席位置で保管場所を即座に記録・検索できるツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/parking-ticket-lost-preventer/）。
2. 画面の指示に従って操作します。
